# Landmine Soft – Frontend Redesign Task

A modern **frontend redesign of the Landmine Soft website** completed as part of a **Frontend Internship Task**.
The goal of this project was to improve the **UI design, layout structure, and responsiveness** using modern frontend tools.

---

## 🚀 Tech Stack

* React.js
* Tailwind CSS
* Lucide React Icons
* JavaScript (ES6)

---

## ✨ Features

* Modern and clean UI
* Fully responsive layout
* Reusable React components
* Sidebar navigation
* Interactive icons and hover effects
* Structured component-based architecture

---

## 📂 Project Structure

```
src
 ├── assets
 ├── components
 ├── pages
 ├── App.jsx
 └── main.jsx
```

---

## ⚙️ Installation

Clone the repository

```
git clone https://github.com/yashpal0502/LandmineSoft-Frontend-task.git
```

Navigate to project folder

```
cd frontend
```

Install dependencies

```
npm install
```

Run development server

```
npm run dev
```

This project was created **as part of a frontend internship task** to demonstrate frontend development skills including **React component design, responsive layouts, and UI improvements**.
